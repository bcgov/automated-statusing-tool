# Changes made on 2026-10-01

This document records the code changes made by the assistant in this session. It does not describe unrelated or user-authored working-tree changes.

## Oracle AOI geometry binding

### Why

The AOI was successfully parsed by Oracle when sent as WKT text to
`SDO_GEOMETRY(:wkt_aoi, :srid)`. The adapter previously sent Shapely-generated
WKB bytes as a BLOB to `SDO_GEOMETRY(:wkb_aoi, :srid)`, which raised
`ORA-13198` in the user's test.

### Files and changes

- [`ast_engine/core/data_adapters/oracle/geometry.py`](ast_engine/core/data_adapters/oracle/geometry.py)
  - Added `aoi_to_wkt_srid(aoi)`.
  - It unions all AOI geometries, obtains the EPSG code from the GeoDataFrame
    CRS, and returns `(WKT, SRID)`.
  - It writes 3D geometries as 2D WKT because this overlay flow operates in 2D.
  - The existing `aoi_to_wkb_srid(aoi)` helper remains in the module; the
    Oracle adapter no longer uses it.
- [`ast_engine/core/data_adapters/oracle/adapter.py`](ast_engine/core/data_adapters/oracle/adapter.py)
  - Switched the AOI conversion from `aoi_to_wkb_srid` to `aoi_to_wkt_srid`.
  - Changed the bind dictionary from `wkb_aoi` to `wkt_aoi`, retaining `srid`
    and the existing optional `srid_t` behavior.
  - Changed the Oracle input bind type from `DB_TYPE_BLOB` to `DB_TYPE_CLOB`.
- [`ast_engine/core/data_adapters/oracle/queries.py`](ast_engine/core/data_adapters/oracle/queries.py)
  - Changed the AOI geometry bind to `:wkt_aoi` in the `intersects`,
    `within_distance`, `touches`, and `nearest` SQL templates.
  - Updated the module documentation to describe the WKT bind.
- [`ast_engine/core/data_adapters/oracle/utils.py`](ast_engine/core/data_adapters/oracle/utils.py)
  - Updated the coordinate-transform SQL rewrite to recognize
    `SDO_GEOMETRY(:wkt_aoi, :srid)` and wrap it in `SDO_CS.TRANSFORM` when AOI
    and table SRIDs differ.
- [`ast_engine/tests/unit/test_adapter_oracle.py`](ast_engine/tests/unit/test_adapter_oracle.py)
  - Added a test that checks the adapter binds a polygon AOI as WKT/CLOB and
    retains SRID 3005.
  - Added a test that checks the transformed-SRID SQL uses the WKT bind and
    supplies `srid_t`.
