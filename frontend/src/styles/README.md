# `styles`

Contains global and shared styling.

Possible contents include:

- Global application styles.
- SCSS variables.
- Design tokens.
- Shared mixins.
- Typography defaults.
- Application-wide layout rules.

## Guidelines

Prefer component-specific styles for component-specific UI.

Use this folder for styles that genuinely need to be shared across the application.

Use BC Government Design System styles/components where appropriate rather than recreating established patterns.

Avoid putting large amounts of unrelated component styling into a single global stylesheet.
